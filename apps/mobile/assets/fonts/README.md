# Fonts

## Selawik

`Selawik-*.ttf` are from Microsoft's open-source Selawik family
(https://github.com/microsoft/Selawik, release 1.01), licensed under the
SIL Open Font License 1.1.

Several text layers in the PowerWatch Figma file are set in "Segoe UI", which
ships only with Windows and cannot be bundled in an app. Selawik is Microsoft's
metric-compatible substitute, so text set in it occupies the same width and
wraps on the same words as the design.

Inter and Hanken Grotesk, the design's other fonts, come from the
`@expo-google-fonts` packages.
